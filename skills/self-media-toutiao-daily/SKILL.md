# 头条号每日工作流

## 目标

把“多发几篇”改成“让一篇通过冷启动”。每日只生产有独立用户价值的内容，并将选题、证据、标题、视觉、声明、发布和复盘连接成闭环。

## 启动

1. 读取工作区的账号定位、近 7 天标题、最近复盘和未完成任务。
2. 读取 [平台规则](references/platform-rules-2026-07-29.md)。规则可能变化；涉及精确限制、声明或权益时，优先核验当前官方页面。
3. 复制 [每日任务卡](assets/toutiao-daily-task-template.md) 建立当天任务。
4. 只在用户明确授权后发布。默认交付发布包或草稿。

## 每日流程

### 1. 扫描信号

按顺序收集：

1. 与账号定位直接相关的官方一手信息。
2. 用户自有案例、观察和历史判断。
3. 平台内读者问题、评论和搜索需求。
4. 近 7 天已发内容和表现。

记录来源、发布时间、适用对象、失效时间和不确定项。时效稿没有一手来源时停止。

### 2. 建立候选选题

每个候选题按以下条件判断：

- 影响对象明确。
- 存在新的事实、判断或行动价值。
- 读者看完能做出决定或完成操作。
- 与近 7 天内容具有独立价值。
- 有足够证据支撑标题承诺。

优先级：

- `P0`：短期失效的官方更新，核验后立即生产。
- `P1`：当前阶段的决策冲突和高频问题。
- `P2`：长期有效的规则、方法和案例。

同一事件默认只生产一篇主稿。只有出现新事实、对象或行动变化时才做后续稿。不要把同一内容机械改成文章和微头条重复发布。

### 3. 选择内容形态

- 信息复杂、需要解释因果或行动路径：文章。
- 单一变化、简短提醒或一个明确判断：微头条。
- 同题已有主稿：不再用另一体裁复述；改做补充问答、案例或等待新信息。

### 4. 建立证据包

写正文前整理：

- 一句话核心判断。
- 受影响对象。
- 关键日期、条件和行动。
- 至少一项信息增量。
- 事实、判断、推断和建议的边界。
- 不应写入标题的未证实内容。

教育、医疗、财经、法律等高风险内容优先使用主管部门、原始文件和可追溯材料。

### 5. 生成并筛选标题

先写三个差异明显的标题，再选择一个：

1. 对象或事件 + 变化 + 行动。
2. 决策冲突 + 判断标准。
3. 关键状态 + 后果或下一步。

拒绝空洞提醒、模糊指代、强迫阅读、夸大情绪和未兑现悬念。标题必须与最近 7 天标题做同题检查。

运行：

```bash
python3 scripts/check_toutiao_package.py <草稿.md>
```

精确标题长度和其他可配置阈值见 [内部验收线](references/internal-gates-2026-07-29.md)。

### 6. 写正文

前 120 字完成：

1. 发生了什么。
2. 谁受影响。
3. 现在该做什么。

主体按“事实 → 解释 → 风险 → 行动”组织。每个小节只解决一个问题。时效稿使用绝对日期，不用脱离发布日期后会失真的“今天、明天、刚刚”。

结尾说明后续会持续跟踪的同类价值，不使用私域导流、诱导互动或无法兑现的承诺。

### 7. 设计视觉

- 封面与标题共同说明同一主体，不制造第二种含义。
- 优先使用自有图、官方材料、合法图库、流程图和数据图。
- 正文图片必须增加信息量，不能只作装饰。
- 保留图片来源、授权或生成方式。

### 8. 判断声明

分别判断：

- 是否可以声明原创。
- 是否需要 AI 内容标识。
- 是否符合首发或其他权益的独占期。
- 是否开启广告或账号已有收益权益。

AI 生成正文不得为了收益机械声明原创。无法确认声明资格时，使用保守选项并在任务卡记录原因。

### 9. 发布预检

逐项通过：

- 来源、日期、对象和数字可核验。
- 标题、封面、首屏和正文一致。
- 与近 7 天内容无实质重复。
- 正文有明确判断或行动价值。
- 错别字、断句、图片版权和声明已检查。
- 任务卡记录最终标题、形态、优先级和观察窗口。

发布前再次运行校验脚本。失败时不发布。

### 10. 选择发布时间

- `P0`：完成核验后立即发布，时效优先。
- `P1/P2`：按实验计划选择时段。
- 不把其他平台的固定发布时间直接照搬到头条。
- 每轮只测试一个主要变量，至少积累同类样本后再判断。

### 11. 观察冷启动

记录发布后 2 小时、24 小时和 7 天数据：

- 展现量。
- 阅读量和点击率。
- 阅读完成率或平均阅读时长。
- 点赞、评论、收藏和转发。
- 新增关注。
- 是否修改过标题或封面。

不要因早期数据低而删除重发。符合平台条件时优先在原文修改，并保留修改记录。

### 12. 日终决策

只做一种决策：

- `SCALE`：复用选题结构，不复制正文。
- `REPACKAGE`：保留内容，重做标题或封面。
- `DEEPEN`：补案例、解释或行动路径。
- `STOP`：停止该题或该包装。
- `WAIT`：样本不足，继续观察。

将结果写入 [单篇复盘卡](assets/toutiao-content-review-template.md)。

## 周期复盘

### 每 7 天

比较同体裁、相近时间窗口的中位数：

- 哪类选题能获得初始点击。
- 哪类正文能维持阅读。
- 哪类内容能带来关注。
- 哪些标题、封面或发布时间仍只是猜测。

只保留一个下一轮实验。

### 每 14 天

更新：

- 主线、副线和资产型内容比例。
- 可复用选题结构。
- 禁用标题句式和重复母题。
- 内部基线与验收线。
- 发布频率。

不要因单篇爆发调整长期定位。

## 完成标准

只有同时满足以下条件才标记 `DONE`：

1. 每日任务卡完整。
2. 草稿和素材真实存在且可打开。
3. 校验脚本通过。
4. 声明和版权状态明确。
5. 发布动作获得授权，或已交付完整手动发布包。
6. 已建立 2 小时、24 小时和 7 天复盘入口。

存在未核实事实、重复内容、声明风险或校验失败时，标记 `BLOCKED`，不要用赶时效作为放行理由。
